# Group-2-Section-4-Formative-Assessment-11
Mixed-Design Repeated Measures ANOVA in R

# Activity Overview & Objectives
In this assessment, you will analyze rat growth data from Box (1950) available in the nlmm R package (rats dataset). You will determine whether rat body weight differs significantly across three treatment groups (Control, Thiouracil, Thyroxin) and across five measurement occasions (Week 0 to Week 4), specifically investigating the Treatment × Time interaction.
